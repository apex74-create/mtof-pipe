MTOF Pipe

Transit host for the house transport (MTOF — Multiplex TOken Format) first end-to-end proof, November 21, 2026. This subdomain serves one file: envelope.mtof.json — a tokenized payload in an enriched JSON envelope, published here so a far-end receiver can fetch it over plain HTTP and un-convert it in the house method. The token layer is the house format; no TLS is used or needed for this proof fetch.
